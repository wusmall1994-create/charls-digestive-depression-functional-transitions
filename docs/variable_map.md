# Core variable map

| Construct | CHARLS source | Operational definition |
|---|---|---|
| Digestive disease | Harmonized CHARLS `digeste`/`digestf` wave variables | Self-reported physician diagnosis of stomach or other digestive disease. |
| Depressive symptoms | Harmonized CHARLS `cesd10` | CES-D 10 score ≥10; ≥12 in sensitivity analysis. |
| ADL limitation | Six basic-activity items / harmonized ADL measure | Difficulty in any basic activity; at least two difficulties in sensitivity analysis. |
| IADL limitation | Five comparable instrumental-activity items | Difficulty in any instrumental activity; at least two difficulties in sensitivity analysis. |
| Death | Harmonized interview status and 2020 sample/exit information | Absorbing destination state. |
| Sleep duration | Health Status and Functioning `da049` | <6, 6–8, >8 hours, or missing. |
| Grip strength | Biomarker modules `qc003`–`qc006` | Maximum valid reading when at least two readings are available. |
| Co-occurrence history | Repeated four-state exposure variable through each interval origin | Current depressive symptoms only without/after prior co-occurrence, first observed co-occurrence, or repeated co-occurrence. |
| Cumulative co-occurrence burden | Repeated four-state exposure variable through each interval origin | One observed co-occurrence wave versus at least two observed waves among currently co-occurring intervals. |
| Covariates | Harmonized CHARLS baseline variables | Age, sex, education, marital status, hukou, smoking, alcohol use, BMI, household income, and other chronic-condition count. |

Variable names are provided solely to document the analysis. Users must consult the CHARLS codebooks for release-specific labels, skip patterns, and access conditions.
